# LifeFork 人生地图交互规范

> 状态：V0.8 当前实现契约
> 适用模块：`src/components/ForkPaths/`
> 责任团队：Life Map Team
> 最后复验：2026-07-31

## 1. 目标

人生地图用于同时表达三类关系：

1. 从出生到当前问题的既有时间线。
2. 从当前问题出发的多个长期方案。
3. 每个长期方案在十年、阶段、年、月、周、日、小时尺度中的嵌套节点。

地图首先保证结构准确和操作可预测。装饰、动画和叙事效果只能建立在这些条件之上。

## 2. 核心不变量

### 2.1 单一节点实体

- 同一 `ForkPath.id` 在场景中只能对应一个节点实体。
- 节点切换尺度时在实体卡和时间容器之间形变。
- 禁止为不同尺度复制同一节点。

### 2.2 父子包含

- 子节点代表的时间范围必须位于父节点时间范围内。
- 当前尺度可见的直属子节点必须位于父节点的可见容器内。
- 隐藏的更深层节点不能提前撑大当前可见容器。
- 拖动父节点时，全部后代保持相对位置并一起移动。
- 拖动后，祖先的可见容器重新计算边界。

### 2.3 稳定拓扑

- 缩放和尺度切换不能改变节点的世界坐标。
- 父子、兄弟和历史节点的相对位置保持稳定。
- 相机只改变 `x`、`y` 和 `zoom`。
- 手动平移结束后不能自动回弹。

### 2.4 尺度展开

- 一个节点只有在当前尺度至少能显示一个直属子节点时才变为虚线容器。
- 子节点尺度尚未到达时，父节点保持实体卡。
- 当前尺度的实体卡文字必须可读。
- 上一尺度的父容器保留为低干扰背景，并保持可点击。

### 2.5 连线

- 普通实体节点从右边缘连接到下一个实体节点的左边缘。
- 已展开父容器到内部子节点的线从父框内部左侧开始。
- 线的端点必须落在对应节点或容器边界上。
- 聚焦父子关系时，目标线使用高亮色，其余可见连线降到低透明度。
- 禁止出现没有可见目标节点的悬空线。

## 3. 场景模型

`stableScene.ts` 负责建立固定世界坐标：

```text
ForkPath tree
  -> measureSubtree
  -> assignSubtree
  -> refreshContainers
  -> StableLifeMapScene
```

核心对象：

| 对象 | 作用 |
| --- | --- |
| `StableSceneNode.card` | 节点实体卡的固定坐标 |
| `StableSceneNode.container` | 完整子树的最大静态边界 |
| `SceneVisibility.containerById` | 当前尺度下的动态可见容器 |
| `StableSceneLink` | 固定父子或历史连接 |
| `overviewBounds` | 桌面初始概览范围 |
| `worldBounds` | 手动平移和 SVG 的完整世界范围 |

`containerById` 只包含当前尺度已经显示的后代。渲染、连线和“当前节点与子节点”取景都应优先使用它。

## 4. 可见性规则

`deriveSceneVisibility` 的输入：

- `scene`
- `activeId`
- `semanticRank`
- `focusMode`

输出：

- 当前路径 `lineageIds`
- 已展开节点 `expandedIds`
- 当前可见节点 `visibleIds`
- 旁路参考节点 `contextIds`
- 高亮连线 `highlightedLinkIds`
- 动态父框 `containerById`

规则：

1. 当前节点和祖先始终可追溯。
2. 父节点的兄弟可作为低透明度上下文。
3. 当前尺度未到达的子节点不显示。
4. 节点没有可见直属孩子时不加入 `expandedIds`。
5. 当前根方案展开时，其他根方案可以隐藏，降低画面干扰。

## 5. 相机规则

### 5.1 桌面初始镜头

- 使用 `overviewBounds`。
- 显示主要历史节点、当前问题和长期方案根节点。
- 最低初始缩放为 `0.5`。

### 5.2 手机初始镜头

- 使用当前问题卡片作为镜头中心。
- 当前问题的屏幕中心与地图视口中心误差应小于 2 px。
- 左侧保留来路线索，右侧保留未来分支线索。
- 用户通过平移和缩放继续查看完整时间线。

### 5.3 尺度按钮

- 切换尺度前先计算新尺度可见性。
- 当前节点出现直属子节点时，自动进入“当前节点和子节点”模式。
- 相机一次性 fit 新的动态父框。
- 没有可见子节点时，保持实体卡并按目标尺度居中。

### 5.4 手动缩放和平移

- `+`、`-` 围绕视口中心缩放。
- 滚轮向上或触控板放大手势增加 zoom。
- 滚轮向下或触控板缩小手势降低 zoom。
- 触控板双指移动和空白处拖动只改变相机位置。
- 手动操作完成后保留镜头。
- 点击节点、切换尺度和重置镜头可以重新启用自动聚焦。

## 6. 双击聚焦状态机

双击当前节点按以下顺序循环：

```text
只看当前节点
  -> 父节点和当前节点
  -> 当前节点和子节点
  -> 只看当前节点
```

验收要求：

| 模式 | 必须完整入镜 |
| --- | --- |
| `single` | 当前节点卡片 |
| `parent-self` | 父节点卡片和当前节点卡片 |
| `self-children` | 当前节点动态容器和全部可见直属子节点 |

进入 `self-children` 时，如果当前尺度未到达子节点尺度，系统先切换到最早的直属子节点尺度。

## 7. 节点拖动

拖动功能仅在“调整布局”模式启用。

1. 指针位移除以当前 zoom，转换为世界坐标位移。
2. 位移写入节点自己的 offset。
3. `assignSubtree` 将祖先累计 offset 传给全部后代。
4. `refreshContainers` 重算祖先完整边界。
5. 用户结束拖动后写入 `lifefork.lifeMapOffsets`。
6. 单轴 offset 限制在 `-1800` 到 `1800`。

拖动不能改变 `parentId`、时间范围、尺度或节点顺序。

## 8. 性能约束

- 场景构建只在路径数据或布局 offset 变化时执行。
- 可见性只在场景、当前节点、尺度或聚焦模式变化时执行。
- 页面只渲染 `visibleIds` 中的节点。
- SVG 只绘制两端都可见的连线。
- 指针移动期间关闭 transform transition。
- wheel 和 pointer 监听器必须在组件卸载时释放。
- 定时器和 `ResizeObserver` 必须清理。
- Public Beta 默认节点总数低于 120，可见节点低于 24。

禁止：

- 每帧重新生成整棵树。
- 在 pointer move 中写入 localStorage。
- 同时运行多个 Next 开发服务器做视觉验收。
- 对地图背景使用大面积高成本 blur 或持续动画。

## 9. 必测场景

### LM-01 初始全人生

- 桌面可见过去、现在和未来根分支。
- 手机当前问题居中。
- 当前尺度文字可读。

### LM-02 长期方案展开

- 选择“方案 C：先做 90 天试验”。
- 切换“一年”。
- 父框、`90 天`和`10 年后`同时完整入镜。
- 两个孩子都位于父框内。

### LM-03 跨级空窗

- 选择 `90 天`节点。
- 当前尺度为“一年”。
- `90 天`保持实体卡，因为直属孩子从“一周”开始。
- 不出现空虚线框。

### LM-04 周尺度展开

- 切换“一周”。
- `第 1 周`和`第 3 周`同时位于 `90 天`父框内。

### LM-05 三种聚焦

- 连续双击当前节点。
- 三种状态按固定顺序出现。
- 每种状态要求的节点完整入镜。

### LM-06 关系高亮

- 在父子聚焦状态下，目标线 opacity 约 `0.94`。
- 其他可见线 opacity 不高于 `0.08`。

### LM-07 缩放和平移

- `+` 后 zoom 增大。
- 滚轮向上后 zoom 增大。
- 空白处向左上拖动 90/30 px，相机平移约 -90/-30 px。
- 松手 400 ms 后位置不回弹。

### LM-08 布局编辑

- 拖动父节点。
- 子孙节点相对位置不变。
- 祖先容器继续包含全部可见后代。
- 刷新后 offset 恢复。

### LM-09 重置

- 点击重置后回到全人生尺度。
- 桌面恢复概览；手机恢复当前点居中。

### LM-10 资源稳定

- 连续操作地图 10 分钟。
- 可见节点和连线数量没有持续增长。
- 页面无重复事件监听器和未清理定时器警告。
- 生产服务 RSS 不发生持续单调增长。

## 10. 变更门禁

任何涉及以下文件的 PR 都必须执行 LM-01 至 LM-10：

- `LifeMapCanvas.tsx`
- `LifeMapNode.tsx`
- `LifeMapLinks.tsx`
- `model/stableScene.ts`
- `model/visibility.ts`
- `model/camera.ts`
- `constants.ts`

PR 报告必须包含：

1. 修改的不变量。
2. 受影响尺度。
3. 桌面和 390 px 手机截图。
4. 缩放前后 transform。
5. 父子节点 bounding rect。
6. `npm run check` 和 `npm run build` 结果。
7. 已知限制和回滚方式。
