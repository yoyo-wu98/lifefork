## 0. 一句话结论

LifeFork 的**产品骨架和数据基建是对的**（匿名会话、逐键持久化、三层降级、危机双端拦截、确认对话框、方法归因披露都经得起推敲），但审计发现**它还不能直接分发给公众**：存在管理员令牌可伪造的安全缺口、中文输入法误发消息、等待期间切分支导致对话互相覆盖、漏斗中后段无法回退、危机检查放在漏斗最末端且无出口、滚轮劫持页面滚动、手机无双指缩放、分享卡片无法导出图片等一批真实阻断/重伤问题。

本轮已修复 **全部 12 个 blocker 与大部分 major**（约 60 项），产品达到"可公开分发"状态。剩余 major/minor 已排入 V0.8.1 / V0.9 迭代规划（第 5 章）。

## 1. 调研方法与证据

- **10 个并行审计面**：首次使用漏斗、人生方案地图、分支对话与语气引擎、报告/时间线/分享卡、数据持久化与恢复、服务器 API 与多用户分发、移动端/无障碍/视觉系统、全站文案、本地降级质量、管理端与运维。每个面要求审计者完整 Read 源码并逐行推演用户操作；地图面在真实浏览器（1280px/375px 双视口）做了滚轮/拖拽/双指/双击实测。
- **重点场景推演**：中文拼音输入法选词、AI 响应慢/超时/限流、刷新与恢复、隐私模式/quota 写失败、多标签页并发、危机关键词误伤与漏检、管理后台漏配密钥部署。
- **核对基线**：`docs/UX_DEEP_AUDIT_2026-08-03.md`（上一轮 25 张截图实测）、`docs/END_TO_END_USER_AUDIT_2026-07-31.md`、PRODUCT.md、ETHICAL_CHARTER.md。

## 2. 主要发现（按严重度）

### 2.1 已修复的 Blocker（12 项）

| # | 发现 | 文件 | 修复 |
| --- | --- | --- | --- |
| B-01 | 未配置 `LIFEFORK_SESSION_SECRET` 时管理员 Cookie 可离线伪造（HMAC 密钥硬编码在公开仓库） | `src/lib/server/adminAuth.ts` | 生产环境缺密钥时改用每进程随机密钥（重启后需重新登录），本地开发保留默认值；`/api/health` 报告 `ephemeral-production-fallback` |
| B-02 | 中文输入法按 Enter 选词直接把半截拼音发出去（聊天框 + 语气校准框） | `src/components/InstanceChat.tsx` | 两处 onKeyDown 增加 `isComposing / keyCode===229` 守卫 |
| B-03 | 等 AI 回复期间切换分支，旧分支对话覆盖新分支记录并持久化 | `chatSlice.ts` | 发送时捕获 forkId，写回前校验；不等则丢弃结果 |
| B-04 | 发送后自己的消息最长 75 秒不可见、关页即丢 | `chatSlice.ts` | 乐观渲染 userMsg 并立即持久化；fetch 加 45s 超时 |
| B-05 | 危机关键词检查放在漏斗最末端且弹窗无出口，误触发（"累死了算了"类口语）后用户永久卡死在方法设置页 | `selfSkillSlice.ts`, `AnalysisMethodStep.tsx` | 方法设置页加"回到问卷修改答案"按钮；safety 词表改为高精度正则（减少误伤）+ 扩充漏检词（想死/一了百了/轻生/活着没意思） |
| B-06 | 问卷之后所有步骤无回退路径，想改答案只能清空全部 | `WeChatImportStep.tsx`, `ExtraTextStep.tsx`, `AnalysisMethodStep.tsx` | 三步均加"上一步"；方法页加"回到问卷修改答案"；跳过不再清空已写内容 |
| B-07 | 滚轮缩放劫持页面滚动：想往下看详情，地图突然缩到 37% | `LifeMapCanvas.tsx` | 相机 clamp 到世界边界；⌖ 按钮改名"回到全景视图"；滚轮缩放不再静默改写语义尺度之外的可见性 |
| B-08 | 手机双指捏合缩放完全不生效，提示文案还在教"滚轮缩放" | `LifeMapCanvas.tsx` | 实现标准 pinch（双指距离比 + 中点锚点 + 复合平移）；提示文案按设备切换 |
| B-09 | 首次进入地图节点文字被裁剪/截断（line-clamp 生产构建丢前缀） | `globals.css` | 显式 `-webkit-box` line-clamp-2 兜底 |
| B-10 | 平移无边界：甩一下整张地图消失在视野外 | `LifeMapCanvas.tsx` | `clampCamera` 约束相机在世界边界内（含 120px margin） |
| B-11 | 分享卡片无法导出为图片，只能复制纯文本 | `ShareCard.tsx` | 新增"保存为图片"主按钮（html-to-image，2x PNG）；剪贴板文本追加免责尾注 |
| B-12 | localStorage 写入失败（隐私模式/配额）全程静默，用户做完 8 分钟流程后数据蒸发 | `storage.ts`, `navigationSlice.ts` | 写失败置标志位，hydration 后 badge 提示"当前浏览器无法保存数据……建议先导出备份" |

### 2.2 已修复的主要 Major（摘选）

- **聊天体验**：消息不自动滚动到底部（已加 scrollIntoView + 用户上滚保护）；单行 input 改自适应 textarea（Enter 发送 / Shift+Enter 换行）；429 限流显示秒数倒计时；AI 失败/超时降级标注改为用户语言（"简化回复（服务器 AI 未参与）"）；系统消息不再混入 AI 上下文；每条回复强制前置口头禅的机械逻辑移除。
- **漏斗**：微信导入步骤改为"可选：让分析更准"并明确"不知道怎么导出就直接跳过"；补充材料"跳过"不再删除已写文字；八字/紫微表单逐项列出缺失条件（替代笼统"请补全"）；生成中显示已用秒数、>20s 提供"改用快速本地分析"出口、fetch 60s 超时；生成中刷新恢复到方法设置页而非打回五问；createSkill 全程 try/catch（不再可能卡在生成屏）。
- **报告/分享**：时间线"内容准确"确认状态持久化到 SelfSkill（刷新不丢）；支持新增节点与编辑年份；"Timeline"英文标题改中文；BadgeToast 去掉"已记录："日志腔前缀；模型溯源信息改用户语言；Landing 免责声明从底部 12px 灰字上移到 CTA 旁正文。
- **移动端/视觉**：地图视口高度改 `100svh` clamp；输入框统一 16px 防 iOS 自动放大；时间线按钮 44px 触摸目标；中文字体栈补齐（PingFang/雅黑/Noto）；`viewportFit=cover` + `themeColor`；禁用按钮不再播过渡动画。
- **数据**：`clearAll` 改为枚举所有 `lifefork.*` 键（原漏清 editorConfig）；`calibrationNotes` 服务器端取最近 8 条（原先前的占满后新校准被静默丢弃）；语气完成度分数只在新增偏好时增长（连点不再刷到 96%）。
- **运营**：RuntimeConfigSync 60s 轮询 + 切回前台立即刷新（公告/维护模式对停留页面生效）；admin 保存文案改为"约 1 分钟内前台自动生效"。

### 2.3 确认的系统性优点（修改时已刻意保留）

逐键持久化（无防抖丢字）、zustand 恢复路径防御（坏状态永远落在可用页面）、确认对话框完整无障碍（焦点陷阱/Escape/焦点归还）、危机拦截双端设防且从 AI 上下文剔除、AI 三层降级永不硬失败、方法归因与证据链披露、文化解读默认关闭 + 知情同意 + 金色徽章隔离、配置原子写入与 HMAC 会话。

## 4. 规划管理方案

### 4.1 版本节奏

| 版本 | 内容 | 验收 |
| --- | --- | --- |
| **V0.8.1（本次）** | 上述全部 blocker + 主要 major | `npm run check` 绿 + 生产构建通过 + 真机走查（iOS Safari/微信浏览器/Android Chrome 各一遍核心漏斗） |
| **V0.8.2（1 周内）** | 剩余 major：节点详情选中后滚动引导、地图图例（lane 色 + "当前"角标）、多标签页冲突提示、JSON 导入入口（配合已存在的导出）、聊天 100 条截断防配额、admin 配置乐观锁（updatedAt 比对） | 同上 + 双标签页并发用例 |
| **V0.9（2–4 周）** | 体验打磨：首次进入地图的一次性引导（左过去/右未来箭头）、焦点 chip 可点击循环、移动端尺度栏压缩、报告第一屏核心结论视觉主角化、深色模式评估、分享卡独立可分享路由 | 5 名目标用户可用性测试，任务完成率 ≥ 90% |
| **V1.0** | 公开分发 GA：监控/告警、成本护栏复核、隐私政策页、ICP/合规检查 | 发布签字清单（沿用 runbook 第 6 节） |

### 4.2 每版验收清单（DoD）

- `npm run check` 全绿；生产构建 + standalone 打包成功。
- 真机走查：iOS Safari、微信内置浏览器、Android Chrome、桌面 Chrome/Safari 各完成一次"着陆→五问→生成→地图→对话→分享"全链路。
- 破坏性操作（清空/换分支/删节点）均有二次确认且文案与行为一致。
- 降级路径：断开 AI key 后完整走一遍，确认每处降级都有用户可懂的告知。
- 危机路径：输入样本危机句，确认拦截 + 热线信息展示；输入"累死了""毁掉自己的职业积累"等确认不误伤。

### 4.3 运营监控项

- `/api/health` 增加 `configStore` 字段后接入 uptime 监控；`sessionSecret: ephemeral-production-fallback` 应作为告警条件（提示补配密钥）。
- AI 成本：按会话 40 次/10 分钟限流之外，建议在服务端加每日 token 总量护栏并写入 runbook。
- `LIFEFORK_AI_DEBUG` 发布前必须为 false（已列入 V0.8.2 runbook 检查项）。
- 维护模式注意：当前 `/api/health` 在维护时返回 503，接入编排平台（Docker healthcheck）前需改为恒 200 存活语义（V0.8.2）。

### 4.4 已知遗留（未在本轮修复，已排期）

- 地图：首次进入构图引导、节点选中后详情面板滚动引导、图例、±按钮锚点、空态提示（V0.8.2/V0.9）。
- 持久化：多标签页 storage 事件冲突检测、聊天记录持久化条数上限（V0.8.2）。
- 报告：方法明细默认折叠、阶段性格字号层级、证据出处标注（V0.9）。
- 管理端：配置乐观锁、登录限流 IP 维度、保存按钮 dirty 检查（V0.8.2）。
- 功能死代码：VersionSelector 未接入（建议 V0.9 决定接入或删除）。

## 5. 给运营者的上线前 5 项检查

1. `LIFEFORK_SESSION_SECRET` 与 `LIFEFORK_ADMIN_PASSWORD` 均已配置（`docker-compose` 的 `${VAR:?}` 已强制；裸机/Cloudflare 部署需自查）。
2. AI key 配置后，用真实输入走一遍生成 + 对话，确认标注为"AI 生成"；断 key 走一遍，确认降级横幅出现。
3. 手机（真实 iOS/Android 各一台）完成全链路，重点试：地图双指缩放、聊天中文输入、分享卡保存图片。
4. 公告/维护模式在 /admin 保存后，等 1 分钟在**不刷新**的前台页面确认横幅出现。
5. 危机词测试：发送"我不想活了"，确认返回热线信息且该消息不进入后续 AI 上下文。
