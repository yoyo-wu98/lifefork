## 2. 验收目标

本轮从真实用户视角检查完整产品，而非只检查页面能否打开。验收覆盖：

1. 新用户首次使用能否在十分钟内完成闭环。
2. 输入、刷新、返回和重新进入后，关键进度能否恢复。
3. 服务器 AI 是否真实参与画像、方案、语气和对话。
4. 微信材料是否具备本地分析、脱敏、主动发送和删除边界。
5. 人生地图是否保持时间顺序、父子包含、当前尺度可读和稳定缩放。
6. 危机输入、提示词注入、错误请求和权限绕过是否被拦截。
7. 多个匿名访客是否获得独立会话。
8. 管理员能否登录、读取、保存配置并退出。
9. 桌面和 390px 移动视口是否可操作。
10. 长流程和深层地图操作后，服务内存是否保持在可接受范围。

## 3. 用户场景

### 3.1 场景 A：职业与创作选择

输入材料：

- 当前选择：是否辞去稳定工作，认真做内容项目。
- 反复情绪：焦虑、不甘心、害怕失败。
- 过去经历：毕业时因收入顾虑放弃想做的方向。
- 隐藏特征：希望被看见，也担心长期普通。
- 十年目标：真正开始，并建立稳定内容收入。
- 补充材料：当前工作尚可，创作和表达长期没有得到使用，希望先设计验证计划。

该场景通过浏览器完整执行，用于验证首次体验、输入恢复、Self Skill、时间线、方案地图、语气校准、服务器对话、危机拦截和结果导出。

### 3.2 场景 B：关系与边界

该场景由真实 AI 自动验收脚本执行，重点验证：

- 输出能否区别于职业创作场景。
- 核心价值、人格称号和分支是否聚焦关系、边界、责任和沟通。
- 两类用户是否退化成相同模板。

实测两组价值集合 Jaccard 重合度为 0.00，人格称号和方案内容存在明显差异。

### 3.3 场景 C：完整人生示例

完整示例包含 38 个渲染节点，覆盖全人生、十年、阶段、一年、一月、一周、一天和一小时。该场景用于验证：

- 从过去、当前点到未来方案的左到右主线。
- 大尺度容器和小尺度节点的父子关系。
- 逐层展开和当前尺度文字可读性。
- 单节点、父子同屏、当前节点和子节点三种焦点模式。
- 深层节点隐藏、当前层节点显示和路线虚化。
- 移动端可读性与控制区换行。

### 3.4 场景 D：管理员

浏览器验证未登录状态和错误密码反馈；自动验收使用测试环境密码完成：

```text
登录 -> 读取全局配置 -> 原值保存 -> 退出 -> 再次访问受保护接口
```

密码只由测试进程从 `.env.local` 读取，测试输出不显示密码。


- AI 关闭后的显式本地降级。
- 请求结构校验。

### 5.2 浏览器输出质量

职业创作场景生成“谨慎的探索者”画像，核心冲突集中在创作、自主、收入稳定和失败风险。AI 给出的试验方案包含：

- 暂不离职。
- 每周发布 2 至 3 次。
- 连续执行 3 个月。
- 记录阅读、互动和变现线索。
- 为每周投入设置 8 小时上限。
- 三个月后根据数据决定是否扩大投入。

输出与用户材料直接相关，具备成本、指标、时间和下一步。当前结果可用于自我整理与方案比较，不能视为未来成功率。

### 5.3 AI 来源透明度

界面现在区分：

- `服务器 AI · provider / model · latency`
- `方案说明 · 本地生成`
- `本地规则 · fallback reason`
- `安全规则已拦截`

初始消息、模型回复、降级回复和安全回复均有来源。用户可以知道当前内容由谁生成、是否调用模型以及是否发生降级。

## 8. 人生地图验收

### 8.1 当前视觉规则

1. 过去位于左侧，当前问题居中，未来方案向右展开。
2. 当前尺度节点显示为可读实体卡片。
3. 已展开的祖先显示为虚线容器。
4. 直接子节点位于祖先容器的逻辑范围内。
5. 更深层后代保持隐藏，进入下一尺度后展开。
6. 父子线从父节点右侧连接到子节点左侧。
7. 聚焦关系高亮时，其他连线降低透明度。
8. 双击依次切换单节点、父子同屏、当前节点和子节点。
9. 缩放只改变镜头和语义尺度，场景拓扑保持稳定。
10. 节点布局调整会带动完整后代，祖先容器重新包围子树。

### 8.2 本轮地图结果

- 初始全人生尺度：54%。
- 完整示例十年尺度：68%，当前层卡片可读。
- 移动端父子同屏：约 42%，当前卡片标题仍可辨认。
- 十年节点：展开 6 / 6。
- 20 至 30 岁进入阶段尺度：展开 1 / 1。
- 双击三种焦点模式：全部通过。
- 放大、缩小和重置按钮：通过。
- 浏览器控制台：0 个 error，0 个 warning。

当前算法优先保证当前节点和相邻直接子节点可读。完整人生跨度较长时，其他直接子节点继续存在于同一稳定画布中，用户通过移动画布查看。

## 10. 性能与稳定性

### 10.1 本轮观测

- 使用 standalone 生产服务，未运行 Next.js 开发监听器。
- 3003 和 3004 没有监听进程。
- 3005 只有一个 Next.js 服务进程。
- 完整浏览器生成、多个真实 AI 请求、深层地图和移动端切换后，服务进程 RSS 单点观测为 72,256 KB。
- 清洁重启后再次执行产品 15 项与真实 AI 49 项验收，服务进程 RSS 为 46,368 KB。
- 场景 fixture 总节点数为 38，当前视图按语义尺度渐进显示。
- 浏览器控制台在主流程和管理端均无错误或警告。
- `npm audit --omit=dev`：0 个漏洞。

单点 RSS 不能证明长期没有泄漏。扩大测试前应增加 30 至 60 分钟重复生成、聊天和地图缩放的趋势测试，并记录进程 RSS、堆使用量、请求延迟和失败率。

### 10.2 防止再次卡死的运行规则

1. 固定使用 `npm run start:3005` 做验收。
2. 启动前检查 3005 是否已有服务。
3. 不同时运行多个 `next dev`、`next start` 或多个端口副本。
4. 地图默认可见节点不超过设计预算。
5. 指针移动只更新相机或当前拖拽对象。
6. 禁止全画布模糊滤镜、持续阴影动画和无限请求循环。
7. 发布前记录空闲、完整示例和连续操作后的三次内存样本。

## 12. 剩余风险

### P0：扩大访问量前

1. 增加全局 token 日预算、告警和熔断。
2. 将单进程限流迁移到 Redis 或边缘网关。
3. 完成隐私政策、模型提供商清单和数据保留说明。
4. 为危机资源增加地区化入口和人工安全评审。
5. 对至少 50 个匿名化场景进行人工盲评。

### P1：产品质量

1. 将首次生成拆成快速核心结果和异步深度结果，目标首屏低于 6 秒。
2. 为大型微信记录增加分块、去重、增量摘要和删除审计。
3. 用用户留出的真实文本建立阶段语气相似度评估。
4. 深层地图节点按需使用 AI 个性化生成。
5. 建立时间线修改后重新计算方案的显式操作。

### P2：长期能力

1. 增加账号与跨设备同步，同时保留本地模式。
2. 建立 Self Skill 版本历史和可回滚机制。
3. 将行动实验结果反馈到后续分支和语气模型。
4. 建立提供商 A/B、成本、质量和延迟统一评估集。

## 13. 发布结论

当前版本满足限量 Public Beta 的功能门槛：用户可以完成输入、个人分析、时间线、方案地图、模拟对话、结果导出和本地清空；真实 AI、来源追踪、匿名会话、管理后台和安全保护均已验证。

本轮结论为 **有条件通过**。可以推送到 GitHub 并进入受控测试。扩大公开流量前，需要完成预算监控、共享限流、隐私政策、人工盲评和长期压力测试。
